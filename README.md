## Study plan

- **Mon–Fri:** 25 min concepts, 60 min coding, 20 min analysis, 15 min revision.
- **Saturday:** Independent problem-solving and a short timed practice.
- **Sunday:** Re-solve missed problems; review complexity and explanations.
- **Goal:** Around 200+ meaningful problem attempts over 32 weeks (including revisions), with quality over quantity.

## Learning method

1. Understand the problem statement, examples, constraints and edge cases.
2. Start with a correct brute-force idea and explain its time/space complexity.
3. Find repeated work and identify an applicable pattern or data structure.
4. Code your own solution, dry-run it, and test edge cases.
5. Explain trade-offs and re-solve tricky problems after 1, 3 and 7 days.
