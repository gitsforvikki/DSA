## 🗂️ Track new solutions consistently

1. After **independently solving** a problem, check it off or mark it `✅ Solved` in its topic sheet.
2. Save the **original solution + explanation + dry run** in its own Markdown file and link that file from the topic sheet.
3. Add one row to **All confirmed solved problems**, and increase the dashboard total **once**. A problem appearing in several topics counts only once.
4. If an answer needs retry, keep it in the review queue — don't count it as solved.
5. Update the **Last reconciled** date when changing totals.
