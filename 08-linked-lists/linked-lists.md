## Review checklist

- [ ] Explain `next`, `prev`, and `curr` pointers with a diagram
- [ ] Handle empty list, one node, head/tail deletion, and consecutive duplicates
- [ ] Know when a sentinel (dummy) node simplifies pointer updates
- [ ] Explain why `curr.next` must be saved before reversing a link
- [ ] Recognize fast/slow, fixed-gap, reversal, merging, and cycle patterns
- [ ] Solve without copying code and state time/space complexity
- [ ] Revisit incorrect attempts and edge cases
